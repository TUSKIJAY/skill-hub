# Personal Skill Hub

Read README.md for usage and catalog.json for discovery. Read only the selected skill's SKILL.md, then follow its relevant references; never load all skills into context.

- Python 3.10+ standard library for hub.py. On this Mac use /opt/homebrew/opt/python@3.13/bin/python3.13 unless the project acquires a documented environment. No dependency install is needed for hub operations.
- catalog.json is the registry; skills/ contains managed sources. docs/index.html and docs/catalog.md are generated by hub.py build.
- Preserve upstream identity and license notices. A local snapshot does not establish authorship or permit public redistribution.
- Do not import project evidence, private documents, credentials, transcripts, caches or machine runtime state. .local is device-specific and ignored.
- Different installed copies remain inventory references until deliberately reconciled. Do not silently choose whichever file has a newer timestamp.
- Installation never executes skill code or installs its dependencies. Dependency requirements belong to each skill.
- Validate changes with `hub.py check` and `python -m unittest discover -s tests -v`; run `hub.py build` after changing the registry. Use the exact Python launcher above on this Mac.
- This is a private personal repository. Changing visibility or publishing a hosted catalogue requires an explicit user request.

- Inventory presence is not usage evidence. Honor catalog lifecycle: retired skills are history only, excluded from installation and profiles; unconfirmed does not mean active. Deprecation in the Hub does not automatically uninstall an existing machine copy.
