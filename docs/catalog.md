# 技能目录

由 `hub.py build` 生成；编辑 catalog.json。

| Skill | 分类 | 状态 | 用途 |
|---|---|---|---|
| `role-drafter` | collaboration | 可安装 | 按协作约定起草可评审的方案。 |
| `role-executor` | collaboration | 可安装 | 按已定方案执行，并提交验收记录。 |
| `role-reviewer` | collaboration | 可安装 | 评审方案与验收材料，明确通过条件及问题。 |
| `md-to-pdf-cn` | documents | 可安装 | 将 Markdown 转为中文 PDF，保留图片、表格和阅读版式。 |
| `project-brief` | reporting | 可安装 | 用可追溯的 HTML 简报说明进展，支持 agent 按需读取证据。 |
| `research-report-builder` | research | 可安装 | 把调研材料整理成有来源依据的 Markdown 报告。 |
| `agent-cli-bridge` | collaboration | 版本有分歧 | 通过本机命令行调用 Claude、Codex 等助手，获取结果或第二意见。 |
| `multi-agent-discussion-harness` | collaboration | 待整理 | 为多 agent 讨论准备问题、方案、评审和证据的分层工作目录。 |
| `orchestration` | collaboration | 待整理 | 通过 Orca 分派任务、传递消息、等待结果并处理依赖。 |
| `seedmux-team` | collaboration | 待整理 | 在独立终端中组织多个 AI 助手协作并收取执行回执。 |
| `acm-md` | development | 待整理 | 用结构化 Markdown 描述项目模块、关系与变更，方便 agent 按图查找。 |
| `orca-cli` | development | 待整理 | 通过 Orca 命令行管理工作区、终端、仓库和任务附件。 |
| `playwright` | development | 待整理 | 用真实浏览器执行页面操作、截图和交互验证。 |
| `project-harness-engineer` | development | 版本有分歧 | 维护项目启动说明、进展交接、验证入口和 agent 工作约定。 |
| `typesafe-ai` | development | 待整理 | 把专用 AI 能力接入应用，作为可编程的功能单元。 |
| `agent-friendly-md-workflow` | documents | 待整理 | 通过 MinerU 将 PDF、Office 和图片整理为方便 agent 读取的材料包。 |
| `markdown-to-pdf-book` | documents | 待整理 | 把长篇 Markdown、OCR 材料和中文书稿排版为 PDF。 |
| `pdf` | documents | 待整理 | 读取、制作和检查 PDF，关注实际排版与页面效果。 |
| `codebase-to-course` | learning | 待整理 | 把代码库整理成面向非技术读者的交互式 HTML 课程。 |
| `find-skills` | management | 待整理 | 按任务需求查找可用的第三方技能及安装来源。 |
| `task-decomposer` | planning | 待整理 | 把模糊想法梳理成明确目标，再拆成可执行任务。 |
| `kline-extract` | research | 待整理 | 从交易图截图提取结构化数据，并绘制可核对的 SVG 图表。 |
| `target-research-workflow` | research | 待整理 | 组织股票、ETF 等标的的筛选、研究与分析流程。 |
