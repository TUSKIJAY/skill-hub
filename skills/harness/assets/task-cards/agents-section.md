## Task Cards

任务卡位于 `{{TASK_CARDS_DIR}}/`（清单 `index.md`，模板 `task-card-template.md`）。本项目已显式启用，规则如下：

- 只实施状态为“实施中”的那张卡；同一时间最多 `task_cards.max_active` 张（见 `.harness/config.json`，默认 1）。开新卡前，上一张须为“已完成”“未通过”或“阻塞”。
- 只改卡片“声明改动的文件”；要改其他文件，先更新卡片并写明原因。
- agent 可把 script 验收项设为“已执行”并填证据位置；human 验收项只能由人设为“已通过”或“未通过”，记录人填人名，agent 不得代填。
- 所有验收项“已通过”才能把卡片设为“已完成”；有 human 项处于“待人工验收”时，卡片保持“待验收”。
- 汇报时分清哪些项是人验过的、哪些只是脚本执行过。
