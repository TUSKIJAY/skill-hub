# 读取说明

- `read index.json`：仅打开索引，返回项目、结论、时间、各项一句话状态、详情路径和下一步。
- `--item ID`：额外只打开该项详情；列出通过条件、观察结果、结论边界与证据摘要。
- `--item ID --evidence ID`：只返回选定证据的时间、摘要、原文件路径和片段定位，不打开原文件。
- 再加 `--source`：校验源文件 SHA-256 后，只输出指定 JSON Pointer 或行范围；不执行文件，不联网，不递归追踪其他引用。
- 默认正文预算为 4000 字符，截断时另附少量说明。需要更多时显式设置 `--max-chars N`，上限 20000。截断包包含 `truncated: true`、原字符数和提示；不要把截断文本当完整证据。

SHA-256 校验需要读取源文件字节，但字节不会全部进入模型上下文。文件改变时停止；重新核实指定片段并更新快照，不能只替换哈希来假装证据仍然适用。源文件缺失时仍可读取历史摘要，但不能宣称原证据已复核。

条目文件路径限定在简报目录内；原始证据路径可指向已获准读取的项目本地文件。相对原路径以 index.json 所在目录解析。源片段选择器仅支持 JSON Pointer（RFC 6901，如 `/tests/0/result`）或一基闭区间行号（如 `[12,18]`）。同一证据恰有一种选择器，禁止用空 Pointer 默认读整个 JSON。

原始文件可能含敏感数据：先选安全片段；禁止把密钥、身份资料、私密截图等写入简报。不为了让证据链接可点击就复制整个原文件。HTML 中原始路径是本地引用，跨机器可能不可用；对外分享前单独准备脱敏副本和可移植路径。
